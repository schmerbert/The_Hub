# Lineage Research Boundary

This directory preserves research about related projects without silently turning that ancestry into Hub requirements.

## Authority

- `PREBUILD.md` and later active Hub specifications describe the current Hub design.
- Files in this directory describe source projects, conceptual relationships, open interpretations, and possible imports.
- Similarity is evidence for comparison, not adoption.
- No coding task may use a lineage document as its implementation specification.

## Research Sequence

Each source project passes through three distinct stages:

1. **Archaeology** — describe the project on its own terms.
2. **Comparison** — map similarities, differences, corrections, and distance.
3. **Adoption** — record an explicit user decision before changing the Hub.

## Evidence Labels

- **Source-stated:** directly asserted by the source project.
- **User-stated:** supplied by the user as historical or relational context.
- **Observed:** found in code, tests, records, or specifications.
- **Inference:** a proposed interpretation that remains open.
- **Adopted:** explicitly approved for the Hub and entered in `ADOPTION_LEDGER.md`.
