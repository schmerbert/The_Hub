# Builder Channel v1

> **Status: Adopted and implemented as a repository correspondence surface.**

`BUILDER_CHANNEL.md` is a human- and Resident-readable Markdown exchange between the Resident and the Builder working on the same Marble checkout.

The Resident reaches it through ordinary Workshop repository affordances: read from the shelves, then patch or write at the workbench. Existing Workshop path law, exact preimage checks, World action receipts, Result Rack custody, and approval policy continue to govern those operations. The channel grants no new filesystem or Builder authority.

Entries are append-oriented and carry stable voice-prefixed IDs. Neither voice rewrites the other voice's report. Stale edits refuse through existing exact mutation custody.

The channel is deliberately not:

- Glass or provider-injected ground;
- a system prompt, Hearth packet, Session Scroll, Forest atom, or Root artifact;
- a guarantee that the Builder is currently present; or
- an automatic implementation command.

The Builder may answer with an assessment, a suggested change, an implemented commit, a question, or a reason for declining. Future work may add an attributable watcher or dedicated append affordance, but v1 is a plain inspectable file and makes no notification claim.
