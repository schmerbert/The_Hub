## Superseded implementation ancestry

The remaining documents—including First Breath, Orientation Receipt, Wake Ritual, original circulation, Workshop stations/control panel/tool ceiling, and earlier Corner/heartbeat slices—are retained because they explain migrations, compatibility, and why current laws exist. Their historical non-goals do not override later owners.

When two documents appear to overlap, use the precedence table in [`../STATUS.md`](../STATUS.md). If that table cannot answer the conflict, documentation is defective: repair the current owner and this standing index rather than asking readers to infer chronology.
