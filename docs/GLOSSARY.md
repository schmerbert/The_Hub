# The Hub — Clinical Glossary

> **Status: Active orientation reference.** This glossary translates the Hub's lived language into clinical responsibilities. It creates no runtime structure and does not supersede an owning specification. [`STATUS.md`](STATUS.md) remains the current-runtime authority; [`specs/HOUSE_GRAMMAR_V1.md`](specs/HOUSE_GRAMMAR_V1.md) owns constitutional vocabulary.

The Hub deliberately uses spatial and lived language where the implementation supports it. The clinical mapping prevents metaphor from silently gaining authority. “Closest conventional term” means resemblance, not equivalence.
